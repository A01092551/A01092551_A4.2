## Ejercicios

### 4.2 - P1: Compute Statistics
Programa que calcula estadísticas (media, mediana, moda, desviación estándar, varianza) de números en un archivo.

### 5.2 - P2: Convert Numbers
Programa que convierte números entre diferentes bases (binario, octal, hexadecimal).

### 6.2 - P3: Word Count
Programa que cuenta la frecuencia de palabras en archivos de texto.

## Uso

Cada ejercicio se puede ejecutar desde su carpeta `source/`:

```bash
# Ejercicio P1
python 4.2/source/computeStatistics.py

# Ejercicio P2
python 5.2/source/convertNumbers.py

# Ejercicio P3
python 6.2/source/wordCount.py
```

## Test Cases

Los archivos de test cases (TC) se encuentran en las carpetas P1, P2 y P3 respectivamente.
